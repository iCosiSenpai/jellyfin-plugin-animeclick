AnimeClick Metadata

Provider di metadati anime in italiano da AnimeClick.it. Tutte le richieste sono rate-limited e i dati vengono cacheati localmente per rispettare il sito.

Metadati

Usa il titolo italiano come nome della serie. Se disattivato, viene usato il titolo originale giapponese.
Importa la sinossi/trama in italiano dalla pagina dell'anime.
Se attivo, AnimeClick sovrascrive anche titolo originale, studio, rating, data e classificazione (campi che AniList/TMDB/OMDb gestiscono meglio). Se spento (default), AnimeClick fornisce solo i campi localizzati (titolo, trama, generi, tag, cast IT) e lascia i buchi agli altri provider.
Fornisce la locandina italiana di AnimeClick come immagine di fallback per serie/film. Priorità bassa: AniList/Fanart/altro vincono se hanno immagini; AnimeClick riempie solo i buchi.
Importa i generi in italiano (es. Commedia, Fantascienza, Scolastico).
Importa gli studi di produzione (es. MAPPA, ufotable, Kyoto Animation).
Importa il rating medio della community di AnimeClick (scala 1-10).
Importa doppiatori (JP + IT), registi, autori e compositori dalla scheda dell'anime.
Importa tag come Shounen, Seinen, Mecha, Isekai dalla scheda dell'anime.
Scarica i titoli degli episodi in italiano dalla pagina /episodi di AnimeClick. Se un titolo è generico ("Episodio X"), il plugin lo ignora e lascia che i provider inglesi (TMDB, TVDB) forniscano il titolo.
Importa i nomi delle Opening ed Ending solo quando AnimeClick li espone in modo strutturato. Molte schede multimedia contengono solo trailer/PV e in quel caso il plugin lo segnala in diagnostica senza trattarlo come errore.
⚠️ Sperimentale — Raggruppa automaticamente sequel, prequel e spin-off nella stessa collezione. Disattivato di default perché potrebbe creare collezioni indesiderate.

Sinossi episodi in italiano (TVDB / TMDB + Ollama Cloud)

AnimeClick non pubblica sinossi per-episodio. Il plugin usa TVDB come fonte preferita (sinossi IT dirette, zero traduzione/compute) quando abilitato sotto, e in fallback TMDB (overview EN) + Ollama Cloud (traduzione IT). Disattivato di default. Senza questa opzione, le sinossi restano in inglese dai provider nativi Jellyfin (fill-gaps). Carico NAS: solo HTTPS in uscita, zero compute locale; cache per-episodio.
Ottieni una API key gratuita su themoviedb.org/settings/api (tipo Personal / Developer). Lascia vuoto per disabilitare la fonte inglese.
Crea la tua API key su ollama.com/settings/keys (account gratuito). Lascia vuoto per disabilitare la traduzione.
Endpoint chat di Ollama Cloud (default: https://ollama.com/api/chat).
I modelli cloud Ollama sono gated per tier di abbonamento (Free/Pro/Max), non per singolo modello: il Free ha concurrency 1 e limiti di utilizzo (sessione/7gg) — sufficienti per traduzioni cached brevi; il Pro ($20/mese) sblocca modelli più grandi e ~50× più utilizzo. Vedi ollama.com/pricing e il catalogo su ollama.com/search?c=cloud.
Inserisci il tag esatto del modello cloud Ollama (formato nome:cloud).
Timeout per una singola chiamata di traduzione Ollama (default: 30).
TheTVDB espone le sinossi degli episodi già tradotte in italiano: quando la traduzione esiste viene usata direttamente, senza chiamate Ollama e senza compute sul NAS. Se TVDB non ha la traduzione per un episodio, il plugin ricade su TMDB + Ollama (se configurati sotto). Richiede una API key TheTVDB v4.
Registrati su thetvdb.com e crea una API key gratuita dalla tua dashboard. Lascia vuoto per disabilitare la fonte TVDB.
Codice lingua TheTVDB per le sinossi episodi (default: ita). Esempi: ita, eng, jpn.
Verifica le credenziali attualmente inserite nei campi sopra (non serve salvare prima). Mostra status HTTP, corpo della risposta ed eventuali errori dettagliati.
