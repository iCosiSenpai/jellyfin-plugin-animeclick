power_settings_new

                                Abilitazione
                            

                            

                                

                                    
                                    
AnimeClick non pubblica sinossi per-episodio. Il plugin usa TVDB come fonte preferita (sinossi IT dirette, zero compute) quando abilitato sotto, e in fallback TMDB (overview EN) + Ollama Cloud (traduzione IT). Disattivato di default; senza, le sinossi restano in inglese dai provider nativi (fill-gaps).

                                

                            

                        


                        

                            

                                
live_tv

                                TheTVDB — fonte preferita
                            

                            

                                

                                    
                                    
TheTVDB espone le sinossi degli episodi già tradotte in italiano: quando esiste viene usata direttamente, senza chiamate Ollama e senza compute sul NAS. Se TVDB non ha la traduzione per un episodio, il plugin ricade su TMDB + Ollama (se configurati). Richiede una API key TheTVDB v4.

                                

                                

                                    
                                    
                                    
Registrati su thetvdb.com e crea una API key gratuita dalla tua dashboard. Lascia vuoto per disabilitare la fonte TVDB.

                                

                                

                                    
                                    
                                    
Codice lingua TheTVDB per le sinossi episodi (default: ita). Esempi: ita, eng, jpn.

                                

                            

                        


                        

                            

                                
sync_alt

                                TMDB + Ollama Cloud — fallback
                            

                            

                                

                                    
                                    
                                    
Ottieni una API key gratuita su themoviedb.org/settings/api (tipo Personal / Developer). Lascia vuoto per disabilitare la fonte inglese.

                                

                                

                                    
                                    
                                    
Crea la tua API key su ollama.com/settings/keys (account gratuito). Lascia vuoto per disabilitare la traduzione.

                                

                                

                                    
                                    
                                    
Endpoint chat di Ollama Cloud (default: https://ollama.com/api/chat).

                                

                                

                                    
                                    
                                    
I modelli cloud Ollama sono gated per tier di abbonamento (Free/Pro/Max). Il Free ha concurrency 1 e limiti di utilizzo (sufficienti per traduzioni cached brevi); il Pro sblocca modelli più grandi e ~50× più utilizzo. Vedi ollama.com/pricing e il catalogo su ollama.com/search?c=cloud.

                                

                                

                                    
                                    
                                    
Inserisci il tag esatto del modello cloud Ollama (formato nome:cloud).

                                

                                

                                    
                                    
                                    
Timeout per una singola chiamata di traduzione Ollama (default: 30).

                                

                            

                        


                    


                    
                    


                        

                            

                                
auto_fix_high

                                Identifica & Aggiorna
                            

                            

                                
Dopo aver identificato un anime con AnimeClick, usa questo pulsante per applicare subito titoli, trama, cast e immagini senza fare refresh manuale. Risolve il bug di Jellyfin 10.11.x che non triggera il refresh automatico dopo l'Identify.

                                

                                    
                                    
                                    
L'UUID dell'item Jellyfin. Lo trovi nell'URL della pagina del film/serie (Dashboard → libreria → item, copia l'UUID dall'indirizzo).

                                

                                

                                    
                                    
                                    
ID AnimeClick nel formato numero/slug o solo numerico.

                                

                                

                                    
                                    
Le immagini locali (folder.jpg, poster.jpg, backdrop.jpg) sono preservate. Le immagini remote già scaricate vengono rimosse e riscaricate dagli ImageFetcher (Fanart, AniList, TMDB, OMDb). Lascia deselezionato per popolare solo i metadati testuali.

                                

                                
                                

                            

                        


                        

                            

                                
cleaning_services

                                Svuota cache
                            

                            

                                
Rimuove tutti i dati metadati cacheati localmente (ricerche, schede anime, episodi, sinossi TVDB/TMDB, traduzioni Ollama). Al prossimo scan i dati verranno riscaricati freschi. Utile se AnimeClick ha aggiornato una scheda e vuoi forzare il refresh.
