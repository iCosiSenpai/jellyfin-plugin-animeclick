AnimeClick Metadata

Provider di metadati anime in italiano da AnimeClick.it. Richieste rate-limited e dati cacheati localmente per rispettare il sito.

v0.2.10.0 Codice sorgente · Segnala un problema
📖Titoli & Trama
Usa il titolo italiano come nome della serie. Se disattivato, viene usato il titolo originale giapponese.
Importa la sinossi/trama in italiano dalla pagina dell'anime.
Se attivo, AnimeClick sovrascrive anche titolo originale, studio, rating, data e classificazione (campi che AniList/TMDB/OMDb gestiscono meglio). Se spento (default), AnimeClick fornisce solo i campi localizzati e lascia i buchi agli altri provider.
🖼️Immagini
Usa le copertine di AnimeClick come immagine di fallback per serie/film. Priorità bassa: AniList/Fanart/TMDB vincono se hanno immagini; AnimeClick riempie solo i buchi.
⚙️Dettagli opzionali
Generi in italiano (es. Commedia, Fantascienza, Scolastico).
Studi di produzione (es. MAPPA, ufotable, Kyoto Animation).
Rating medio della community AnimeClick (scala 1-10).
Doppiatori (JP + IT), registi, autori e compositori.
Tag come Shounen, Seinen, Mecha, Isekai.
Titoli episodi in italiano da /episodi. I titoli generici ("Episodio X") sono ignorati.
Nomi di Opening/Ending quando AnimeClick li espone in modo strutturato.
⚠️ Raggruppa sequel/prequel/spin-off in collezioni. Disattivato di default.
AnimeClick non pubblica sinossi per-episodio. Il plugin usa TVDB come fonte preferita (sinossi IT dirette, zero compute) quando abilitato sotto, e in fallback TMDB (overview EN) + Ollama Cloud (traduzione IT). Disattivato di default; senza, le sinossi restano in inglese dai provider nativi (fill-gaps).
🌐TheTVDB — fonte preferita
TheTVDB espone le sinossi degli episodi già tradotte in italiano: quando la traduzione esiste viene usata direttamente, senza chiamate Ollama e senza compute sul NAS. Se TVDB non ha la traduzione per un episodio, il plugin ricade su TMDB + Ollama (se configurati sotto). Richiede una API key TheTVDB v4.
Registrati su thetvdb.com e crea una API key gratuita dalla tua dashboard. Lascia vuoto per disabilitare la fonte TVDB.
Codice lingua TheTVDB per le sinossi episodi (default: ita). Esempi: ita, eng, jpn.
🔁TMDB + Ollama Cloud — fallback
Ottieni una API key gratuita su themoviedb.org/settings/api (tipo Personal / Developer). Lascia vuoto per disabilitare la fonte inglese.
Crea la tua API key su ollama.com/settings/keys (account gratuito). Lascia vuoto per disabilitare la traduzione.
Endpoint chat di Ollama Cloud (default: https://ollama.com/api/chat).
I modelli cloud Ollama sono gated per tier di abbonamento (Free/Pro/Max). Il Free ha concurrency 1 e limiti di utilizzo (sufficienti per traduzioni cached brevi); il Pro sblocca modelli più grandi e ~50× più utilizzo. Vedi ollama.com/pricing e il catalogo su ollama.com/search?c=cloud.
Inserisci il tag esatto del modello cloud Ollama (formato nome:cloud).
Timeout per una singola chiamata di traduzione Ollama (default: 30).
