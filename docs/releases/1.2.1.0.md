# AnimeClick Metadata 1.2.1.0

**Superata da 1.2.2.0.** Il collaudo sul NAS ha individuato una proposta proveniente dalla stagione sbagliata, senza salvarla. Questa release è stata marcata prerelease/non-latest; usare la correzione 1.2.2.

«Sistema tutti i titoli» recupera anche i titoli riconoscibilmente inglesi, oltre ai nomi mancanti, generici e derivati dal file. Cerca prima il titolo italiano su AnimeClick, poi nelle fonti configurate; quando resta soltanto l'inglese, usa il servizio AI scelto. Conserva i titoli italiani o incerti e rispetta i campi bloccati e le modifiche intervenute durante la ricerca. Scrive soltanto il nome dell'episodio.

- Titoli ancora inglesi, generici, identici all'originale o malformati restituiti dall'AI vengono rifiutati; non entrano nella cache delle nuove traduzioni.
- Test amministrativo su un singolo episodio, con anteprima predefinita senza salvataggio e applicazione esplicita. Permette verifiche sul server esistente senza avviare riparazioni globali.
- Icona cinema nella barra laterale della dashboard Jellyfin 12, al posto della cartella predefinita.
- Risolta la collisione di un tipo API che impediva a Jellyfin di generare il documento OpenAPI.
- README: installazione ufficiale tramite manifest ripristinata come metodo consigliato; installazione manuale presentata come alternativa. Copyright e attribuzioni delle fonti conservati.

Richiede Jellyfin 12.0 / .NET 10; compatibilità verificata anche su 12.1. 361 test backend per ciascuna versione e 19 test browser. Dettagli e limiti in [AUDIT-1.2.1.md](../AUDIT-1.2.1.md).

Release GitHub destinata anche all'installazione sul NAS del proprietario. Il catalogo pubblico rimane invariato per sua richiesta; l'aggiornamento non avvia una riparazione della libreria e conserva configurazione, chiavi e immagini.
