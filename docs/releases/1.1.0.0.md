# AnimeClick 1.1 — la libreria mostra cosa sta facendo

Richiede Jellyfin **12.0 o successivo** e .NET 10. Verificato su Jellyfin 12.0.0 e 12.1.0; il pacchetto usa l’ABI minima `12.0.0.0`.

## La tua libreria

- Analisi locale automatica con indicatore di caricamento, ora dell’ultimo aggiornamento ed errori recuperabili.
- Titoli episodio e trame in viste separate, serie espandibili e diagnostica dettagliata raccolta a parte.
- Attività con fase, barra di avanzamento, contatori degli esiti e pulsante Interrompi. Lo stato rimane visibile tornando alla pagina; due clic non riavviano il lavoro.
- “Sistema tutti i titoli” attende i salvataggi effettivi e aggiorna soltanto i nomi mancanti, segnaposto o derivati dal file. Conserva titoli compilati, trame, immagini, ID e numerazione; ricontrolla blocchi e modifiche manuali prima di scrivere.
- Il recupero delle sinossi distingue aggiornamenti riusciti, attesa, assenza di fonte ed errori; evita di ripresentare lo stesso elemento fermo durante una singola esecuzione.

## Correzioni condivise, solo se lo scegli

Due opzioni indipendenti, entrambe su **No** per impostazione predefinita: leggere gli abbinamenti approvati e inviare automaticamente una proposta quando correggi manualmente un collegamento.

L’invio richiede un token del tuo account GitHub e crea una issue pubblica nel repository del plugin. Include solo tipo dell’opera e ID AnimeClick/TMDB/TVDB/AniList. Non include utenti Jellyfin, file, percorsi, server, cronologia, trame o immagini. Anteprima, esportazione locale, coda persistente, deduplicazione e tentativi limitati sono disponibili nella sezione Comunità. Le stagioni non vengono condivise.

Il dataset iniziale è vuoto. Gli abbinamenti vengono usati dopo la revisione del progetto, solo quando manca un ID AnimeClick e gli ID esterni non sono in conflitto. Non vengono apprese automaticamente segnalazioni non verificate e non viene addestrato un modello AI.

## Aggiornamento e verifiche

Preferenze e credenziali esistenti sono conservate. Installare il plugin non avvia riparazioni della libreria. Le attività già consegnate a Jellyfin per le sinossi possono terminare anche dopo un’interruzione; i dettagli delle attività si azzerano riavviando il server.

232 test backend su ciascuna API Jellyfin supportata, 17 test browser, verifica dentro entrambi i server isolati e controllo delle dipendenze. Dettagli e limiti nel [rapporto di audit](https://github.com/iCosiSenpai/jellyfin-plugin-animeclick/blob/v1.1.0.0/docs/AUDIT-1.1.md).

Questa release è pubblicata su GitHub per l’installazione manuale sul NAS richiesto. **Il catalogo pubblico Jellyfin resta invariato**: non viene distribuita attraverso un aggiornamento del manifest.
