# AnimeClick 1.1.2 — AnimeClick prima, campo per campo

Richiede Jellyfin **12.0 o successivo** e .NET 10. Verificato su Jellyfin 12.0.0 e 12.1.0; il pacchetto usa l’ABI minima `12.0.0.0`.

Ogni campo viene valutato separatamente: **AnimeClick → fonte italiana → fonte inglese tradotta**. Valori come «N/D», «Trama non disponibile» ed «Episode 12» vengono scartati. Un campo valido di AnimeClick non viene rimpiazzato per il solo fatto che un altro campo manca.

- Recupero di titoli e trame anche per serie e film con ID TMDB/TheTVDB già salvati. Le trame inglesi vengono tradotte in background; quelle italiane non richiedono AI.
- Generi italiani TMDB o generi inglesi TheTVDB tradotti; tag inglesi TMDB tradotti, solo quando mancano quelli AnimeClick. Traduzioni delle etichette con array validato e prompt distinto da trame e titoli.
- Gli errori di AnimeClick lasciano disponibili le fonti configurate. Per gli episodi, gli ID esterni già presenti consentono il recupero anche quando la scheda AnimeClick è irraggiungibile. Un ID episodio discordante non viene aggirato cambiando coordinate.
- L’analisi riconosce i segnaposto delle trame come mancanti e propone il recupero dei nomi generici. Rispetta preferenze, blocchi e correzioni manuali.
- Le immagini conservano la precedenza dei provider ad alta risoluzione, come richiesto dal proprietario. AnimeClick resta una fonte di riserva. Nessuna immagine presente viene cancellata o aggiornata dall’installazione.

Si traducono soltanto testi descrittivi. Nomi propri, ID, date e valori numerici conservano il proprio significato. I campi neutri restano controllati dall’opzione avanzata di precedenza AnimeClick, disattivata di default per le altre installazioni; sul NAS del proprietario viene attivata per sua richiesta.

Le fonti e l’AI richiedono le impostazioni e il consenso già disponibili. I servizi AI possono consumare credito. Non vengono scelti servizi o modelli automaticamente. La condivisione GitHub resta facoltativa e disattivata di default.

284 test backend su ciascuna API Jellyfin supportata, 18 test browser e verifica in due server isolati. Le API esterne sono simulate: nessuna chiamata a servizi AI a pagamento per il collaudo. Dettagli nel [rapporto di audit](https://github.com/iCosiSenpai/jellyfin-plugin-animeclick/blob/v1.1.2.0/docs/AUDIT-1.1.2.md).

Release GitHub per l’installazione manuale sul NAS richiesto. **Il catalogo pubblico Jellyfin resta invariato.** L’installazione non avvia riparazioni massive.
