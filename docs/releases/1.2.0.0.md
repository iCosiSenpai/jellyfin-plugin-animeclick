# AnimeClick 1.2.0 — un solo provider, con Fanart integrato

Richiede Jellyfin **12.0 o successivo** e .NET 10. Verificato su Jellyfin 12.0.0 e 12.1.0; il pacchetto usa l’ABI minima `12.0.0.0`.

Nelle librerie anime puoi usare **AnimeClick come unico provider remoto di metadati e immagini**. Le fonti aggiuntive vengono consultate direttamente dal plugin: non servono i plugin Jellyfin TMDB, TheTVDB o Fanart per questa catena.

- AnimeClick resta la prima fonte per ogni campo. TMDB identifica direttamente serie e film tramite ID o titolo/alias esatto, animazione, anno e formato. Remake ambigui e ID discordanti non vengono scelti automaticamente.
- Le fonti integrate completano i testi italiani e i campi neutri mancanti: studi, date, valutazioni, cast, ID pubblici, stato della serie e trailer. Anche stagioni ed episodi ricevono date e ID senza altri provider, conservando la numerazione della libreria.
- Per i testi: AnimeClick → fonte già italiana → testo inglese tradotto con il servizio AI configurato. Tutti gli interruttori restano rispettati; nomi propri, ID e dati numerici non vengono tradotti.
- Per le immagini: **Fanart → TMDB alla risoluzione originale → locandina AnimeClick**. Fanart include sfondi 4K, loghi, banner e artwork delle stagioni. Le impostazioni contengono il link per creare la chiave personale o di progetto e il pulsante «Verifica Fanart».
- L’AI non è richiesta per i testi già italiani e non viene configurata automaticamente. Per la modalità autonoma completa serve la chiave TMDB; Fanart e TheTVDB richiedono le rispettive chiavi. Fanart v3.2 funziona anche con la sola chiave personale.

La modalità integrata è attiva di default; senza chiavi non vengono effettuate richieste a quelle fonti. Puoi disattivarla per continuare a comporre AnimeClick con altri provider. NFO, immagini locali ed estrattori Jellyfin possono restare attivi. Nessun catalogo garantisce tutti i campi per ogni anime: se manca una fonte certa, il valore rimane invariato.

**327 test backend per ciascuna API Jellyfin supportata**, 19 test browser e verifica in due server isolati. API metadati e AI simulate; prova reale gratuita della chiave Fanart fornita dal proprietario. Dettagli nel [rapporto di audit](https://github.com/iCosiSenpai/jellyfin-plugin-animeclick/blob/v1.2.0.0/docs/AUDIT-1.2.md).

Release GitHub per l’installazione manuale sul NAS richiesto. **Il catalogo pubblico Jellyfin resta invariato.** L’installazione non avvia scansioni o riparazioni massive e non sostituisce le immagini presenti. La condivisione GitHub resta disattivata di default.
